# Portfolio artwork folders

Add image files to the matching folder below. Supported formats are AVIF, GIF, JPEG, PNG, SVG, and WebP.

- `freelance/`
- `traditional/`
- `2d-designs/`
- `3d-designs/`

The portfolio discovers these images automatically. In development, Vite refreshes when files are added. For a deployed site, rebuild and redeploy after changing the artwork.
